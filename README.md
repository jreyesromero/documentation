# Documentation

Welcome to the documentation repository for DevOps, Platform Engineers, and SRE engineers. This repository is structured to support technical interview preparation and production troubleshooting.

## Contents

- **[Linux Commands](./linux/linux.md)** — Essential Linux commands reference guide
  - 16 command files (ps, top, systemctl, journalctl, netstat, df, du, find, and more)
  - 50+ real-world SRE troubleshooting scenarios
  - All commands with practical examples and interview tips
  - **Coverage:** 25% of Nebius SRE interview

- **[Networking & Connectivity](./networking/networking.md)** — Network protocols and troubleshooting guide
  - 6 comprehensive files: DNS, TCP, HTTP, TLS, Tools (curl/nc/tcpdump), Troubleshooting Checklist
  - 20+ production troubleshooting scenarios with complete investigation workflows
  - Complete protocol walkthroughs (DNS resolution → TCP handshake → HTTP → TLS)
  - **Coverage:** 20% of Nebius SRE interview

---

**Interview Preparation:** These documents cover the core technical areas tested in SRE interviews. Start with Linux fundamentals, then progress to Networking, Algorithms/Python, DevOps fundamentals, and Kubernetes.

**Production Use:** Each section includes systematic troubleshooting workflows and printable checklists for use during incidents.

**Note:** Each section is organized by topic with detailed command references, concept explanations, real-world scenarios with fixes, common pitfalls, and specific interview tips.
